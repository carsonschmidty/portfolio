# Stock Spyder Frontend Prototype

This is a lightweight prototype of the Stock Spyder interface implemented with React via CDN and Tailwind CSS.

Due to the offline environment, no npm packages or build tools were used. The `index.html` file includes CDN links for React, ReactDOM and Tailwind. Open the file in a browser with internet access to load these assets.

## Pages

- **Dashboard** – Shows summary cards and recent activity.
- **Inventory List** – Example table for managing products.
- **Orders** – Example order list with search input.

Use the sidebar to navigate between pages.

## Running

Simply open `index.html` in a browser connected to the internet.
